# 사용자 화면 1차 구현 · 2026-10-13

## 적용 범위

- 실제 Figma 메인 프레임(PC/모바일, Light/Dark)과 저장된 네이티브 캡처·생성 명세를 기준으로 메인 화면을 구현했다.
- Figma MCP는 Starter 호출 한도로 새 디자인 컨텍스트를 반환하지 못했다. 이전 작업에서 검증한 `native-previews/`와 `design.js`를 사용했으며, 새로 조회한 디자인 컨텍스트로 구현한 것은 아니다.
- 사용자 화면의 사이드바, 상단 검색·계정·테마, 모바일 탐색 탭과 하단 메뉴, 버튼·장르 칩·작품 카드에 공통 디자인을 적용했다.
- 탐색, 상세, 대화, 계정 화면은 기존 구성과 기능을 보존하고 공통 메뉴·카드·색상만 적용했다. 개별 화면의 전체 리디자인은 후속 범위다.
- 스튜디오 파일을 수정하지 않았다. 스튜디오 경로에는 `UserTheme`의 `.user-surface` 래퍼를 렌더링하지 않아 전용 토큰, 폰트, 여백과 테마가 적용되지 않는다.

## 기능 연결

- 상단 검색은 `/explore?q=검색어`로 이동하고 기존 탐색 결과에 검색어를 반영한다.
- 메인의 장르 필터는 장르 정보가 있는 기존 샘플 작품에만 적용한다. 공개 작품에는 확인되지 않은 장르·작가·표지·통계 정보를 붙이지 않는다.
- 공개 작품은 기존 `listCatalog`와 설정된 `NEXT_PUBLIC_FEATURED_PRODUCT_IDS`의 `getPublishedWork` 결과를 사용한다. 표지가 없는 작품에는 대체 표지를 표시한다.
- 최근 대화는 기존 계정별 목록과 브라우저의 시연 대화를 사용한다. 샘플 작품과 실제 API 작품을 명시적으로 구분한다.
- 사용자 테마는 `moseori_user_theme`에 저장한다. 저장값이 없으면 시스템 테마를 따르며 스튜디오의 테마 저장 키는 그대로 유지한다.
- 현재 `AuthUser`에 성인 이용 권한이 없으므로 성인 필터는 렌더링하지 않는다. 이메일 인증을 성인 인증으로 취급하지 않는다. 권한과 목록 필터링 계약이 제공되면 별도 연결한다.

## 배치

- PC: 사이드바 224px, 상단 80px, 본문 좌우 32px, 카드 4열. 사이드바를 접으면 72px.
- 701–1100px: 본문 좌우 24px, 카드 2열. 900px 이하 배너는 설명을 숨기고 이미지를 줄여 제목과 버튼 공간을 확보한다.
- 700px 이하: 좌우 16px, 카드 2열, 배너 256px, 상단 검색과 탭, 고정 하단 메뉴. 370px 이하에서는 배너 이미지·버튼 크기를 추가 조정한다.
- 표지 비율은 3:4. 배너는 같은 원본을 위치별로 크롭하고 최근 대화 표지는 작은 아바타로 표시한다.
- 글꼴은 Figma의 Noto Sans KR을 우선 사용하며, 미설치 기기는 Apple SD Gothic Neo / Malgun Gothic으로 대체한다. 별도 웹폰트 배포는 아직 추가하지 않았다.

## 검증

- TypeScript 검사 통과.
- Next.js 배포 빌드 통과.
- 기존 API 통합 테스트 12개 통과.
- 실제 브라우저에서 1440 / 768 / 701 / 390 / 360px의 가로 넘침 없음 확인.
- 라이트·다크 전환, 테마 유지, 사이드바 접기·펼치기, 장르 필터, 검색어 전달, 작품 상세와 샘플 대화 시작 이동을 확인했다.
- 로컬 표지 4장과 브랜드 SVG가 로드되는 것을 확인했다.
- 사용자 다크모드에서 스튜디오로 이동했을 때 사용자 래퍼·메뉴 없음, body padding 0, 스튜디오의 기존 light 테마 유지 확인.
- 검증 중 백엔드 8000번 포트는 실행되지 않았다. 실제 로그인과 공개 목록의 성공 응답은 미검증이며 조회 실패·재시도 화면을 확인했다.

## 추가 조정 · 로그인과 사이드바

- 로그인 경로에서는 헤더·사이드바·모바일 하단 메뉴를 렌더링하지 않고 메뉴 여백 없이 화면 높이 전체를 사용한다. 기존 폼의 홈으로 돌아가기 링크를 유지한다.
- 로그인 페이지도 루트의 `UserTheme`를 사용해 이전에 저장한 라이트·다크모드를 유지한다. 다크모드에서 로그인 화면으로 이동한 뒤 새로고침해도 `dark`가 유지되는 것을 브라우저에서 확인했다.
- 상단의 현재 페이지 명칭을 제거했다. 사이드바의 이동 메뉴와 모바일 탐색 탭은 유지한다.
- 사이드바 폭, 본문 왼쪽 여백, 상단 위치를 같은 280ms easing으로 전환한다. 고정 폭 메뉴 내용은 페이드와 작은 이동으로 나타나며, 접힌 메뉴는 `inert`와 `aria-hidden`으로 키보드·보조기술 접근을 막는다.
- 모션 감소 설정에서는 전환을 즉시 처리한다.

## 실행 방법

`apps/web`에서 `node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000` 실행 후 `http://127.0.0.1:3000/`을 연다. 기존 `4318` 주소는 디자인 검토용 페이지이며 서비스 구현 화면은 `3000`이다.
