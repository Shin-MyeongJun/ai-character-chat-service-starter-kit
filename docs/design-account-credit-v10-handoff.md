- Desktop 긴 구매 목록도 스크롤 가능하도록 수정. 상세 카드의 고정 텍스트 높이로 잘리던 결제 요약 문구 보완.

## 실제 재생 확인

- 모바일 작품 관리 → 마이페이지 → 지갑 → 구매 내역.
- 완료 주문 → 구매 상세 → 구매 내역 복귀 및 하단 스크롤.
- 확인 중 주문 → 처리 상태 재확인 → 미확정 상태 유지.
- 다크 Desktop 계정 → 지갑 → 구매 내역.
- 다크 대화 → 설정 → 다크 삭제 확인 → 취소 → 대화 복귀.
- 상품 요약 → ‘결제창 열기 · 시연’ → 결제 처리 중.

최종 구조 검사에서 Light가 남은 Dark 인스턴스, Dark 화면의 Light 역할 색상, 의도하지 않은 Light 목적지, 없는 목적지, 상세 카드 내부 잘림, 모바일 968px 작업·편집 영역은 발견되지 않음. 검사 대상 텍스트 1,480개, 컴포넌트 인스턴스 681개, 반응 액션 285개.

## 구현 시 유지할 경계

결제·인증·크레딧 지급·영수증·삭제·저장·검색·필터는 실제 서비스 연동과 구별되는 디자인 시연이다. 실제 결제는 수행하지 않았다. 작품 관리의 제작 스튜디오 링크는 기존과 같이 01 페이지의 공통 시작점을 새 탭으로 열며 작품별 편집 상태를 직접 복원하지 않는다. 기존 테스트 채팅과 이전 모바일 Dark 작품 관리는 ‘보관’ 이름으로 보존했다.

작업 도구: Figma MCP Plugin API로 편집하고, computer-use 스킬의 node_repl + @oai/sky로 마우스·키보드 실제 재생 및 로컬 저장을 수행했다. 입력 후마다 새 상태를 확인했다. API 할당량 소진은 발생하지 않았다.
