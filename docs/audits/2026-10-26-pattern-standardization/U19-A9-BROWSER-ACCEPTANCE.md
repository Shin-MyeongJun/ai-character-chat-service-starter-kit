### 실행 범위와 미실행 사례

- 스튜디오의 이미지 포함 첫 발행 및 재발행은 발행 버튼 제한으로 실행할 수 없었다. 채팅과 앨범에서 관찰한 결과는 동일 기준 커밋의 백엔드 발행 경로를 이용했다.
- 브라우저의 A 노출은 시작 장면으로 재현했다. 모의 모델은 텍스트 답변을 반환하므로 생성 답변이 A를 고르는 브라우저 경로와 외부 LLM 호출은 실행하지 않았다. 생성 답변의 이미지 배치·해금·복구는 백엔드 회귀 테스트 범위에 포함됐다.
- 실기기와 다른 브라우저 엔진은 이번 Windows Chrome 실행 범위에 포함되지 않았다.
- 실패 주입을 준비하는 과정에서 가격표 누락, 긴 스크롤 픽스처의 문맥 상한, 모의 모델의 추론 옵션 제한을 확인했다. 복구 최종 검증에는 합성 가격표와 짧은 시작 장면, 지원되는 추론 설정을 사용했다.
