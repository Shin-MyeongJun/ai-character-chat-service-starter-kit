# 감사 기록과 로컬 실행 증거

감사 보고서와 재현 스크립트는 변경 이유·검증 방법을 보존하기 위해 버전 관리한다.
정식 회귀 테스트는 `apps/api/tests`에 유지한다.

스튜디오·S3 수정의 DB 기동 후 최종 수락 결과는
[2026-11-03 마무리 검증](2026-11-03-iea-studio-fix/FINAL-VALIDATION-2026-11-03.md)을 따른다.
해당 기록은 앞선 스튜디오 수정 보고서의 PG 미검증 상태를 보완한다.

2026-11-02 독립 감사/재검사와 2026-11-03 후속 수정에서 생성한 해시 목록,
작업 트리 상태 덤프, 코드 발췌, 원시 검사 로그와 XML 결과는 로컬 실행 증거다.
이 자료는 로컬에 보존하되 `.gitignore`로 커밋에서 제외한다.
보고서에서 이 파일을 가리키는 링크는 새 clone에는 없을 수 있다.
보고서의 실행 결과 요약과 재현 명령은 그대로 보존한다.

감사 스크립트 일부는 당시 기준 JSON을 입력으로 사용한다. 기준 파일이 없는
새 clone에서 과거 증거 최종화 스크립트를 그대로 실행해 과거 검증을 재생할 수는 없다.
동작 재검증은 보고서에 연결된 테스트와 실행기를 사용하고, 새 실행 기록은
새 폴더 또는 고유한 로그 이름으로 남긴다.

과거 수정 전 결함을 입증하는 테스트는 수정 후 기대 결과가 달라질 수 있다.
현재 코드의 회귀 판정에는 프로젝트의 정식 테스트를 우선 사용한다.
