# 시각적 검수 기록

기준일: 2026-10-21. 최종 PDF 108페이지, 도표 48개.

PDF 전 페이지를 Poppler로 이미지화했다. 전 페이지 축소판을 확인하고 시스템 구성·계층·전체 모듈 의존 지도·다섯 시퀀스·FK 관계도·발견 사항·실제 코드 예시를 확대 확인했다. 마지막 변경은 전체 모듈 의존 지도 한 페이지 추가와 발견 유형 명칭 정리였으며 해당 페이지를 재검수했다.

수정한 사항:

- 시스템 구조도의 SQL 호출과 worker 외부 호출 설명이 겹쳐 외부 호출 선을 하단으로 우회했다.
- 대표 계층도에서 workflow 호출선이 mapper 상자를 관통해 위쪽으로 분리했다.
- 시퀀스의 영문 식별자 줄바꿈을 개선하고 헤더·자기 호출·다음 단계 사이 여백을 늘렸다.
- 시퀀스마다 호출 방향·생명선·시간 순서 범례를 추가했다.
- 큰 FK 그래프는 도메인별 여러 페이지로 나눴으며 테이블 사전은 페이지별 반복 머리글을 사용했다.

결과: 관찰한 페이지에 깨진 한글·본문 잘림·문자 겹침·의도하지 않은 빈 페이지가 없었다. 일부 절 마지막 페이지는 다음 도표를 분리하기 위해 여백이 있다. 긴 경로·식별자는 표 안에서 줄바꿈된다. 전체 도표는 PDF 벡터로 포함되며 별도 PNG는 긴 변 1800픽셀이다.

자동 검사: `qa-results.json`의 문자 경계 위반 0건. 한글 검색·텍스트 추출 성공. Malgun Gothic 일반·굵게 글꼴이 PDF에 포함됨을 확인했다. 기본 Helvetica/Times-Roman 리소스도 있으나 한글 본문은 내장 Malgun Gothic을 사용한다. `source-integrity.json`에서 조사한 입력 파일 변경 0건을 확인했다.

시각 검수는 보고서 레이아웃 확인이며 코드의 동작 검증을 대신하지 않는다. 원본을 편집해 재생성한 뒤에는 이 기록을 자동으로 승계하지 말고 다시 확인한다.
